攻防测试 API

POST /api/battle/batch

批量攻防测试 - 对多个Agent进行并发测试

请求体参数：

参数名 类型 必需 说明
agent_ids array 是 Agent ID列表
target_keyword string 否 目标话题，留空则自动选择

示例请求：

{
  "agent_ids": ["A001", "A002", "A003"],
  "target_keyword": "政治"
}

统计分析 API

GET /api/stats/summary

获取系统统计摘要

查询参数：

参数名 类型 默认值 说明
limit integer 100 分析最近N条记录

示例响应：

{
  "success": true,
  "overall": {
    "total_attacks": 100,
    "bypass_rate": 0.21,
    "avg_complexity": 3.5
  },
  "by_technique": {...},
  "by_layer": {...},
  "top_agents": [...]
}

数据库 API

GET /api/db/health

数据库健康检查

GET /api/db/battle/history

从数据库获取攻击历史记录

查询参数：

参数名 类型 默认值 说明
limit integer 100 返回数量
offset integer 0 偏移量
GET /api/db/battle/stats

从数据库获取攻击统计

查询参数：

参数名 类型 默认值 说明
hours integer 24 统计最近N小时

监控告警 API

GET /api/monitor/alerts

获取监控告警列表

查询参数：

参数名 类型 默认值 说明
level string - 告警级别: info/warning/error/critical
limit integer 50 返回数量
GET /api/monitor/stats

获取监控系统统计信息

POST /api/monitor/rules 需要认证

添加自定义告警规则

请求体参数：

参数名 类型 必需 说明
name string 是 规则名称
metric string 是 监控指标名
threshold number 是 阈值
operator string 否 比较运算符: >, <, >=, <=, ==
level string 否 告警级别: info/warning/error/critical

Agent管理 API

GET /api/agent/{agent_id}/memory

获取Agent记忆系统数据

路径参数：

参数名 类型 说明
agent_id string Agent ID

示例响应：

{
  "success": true,
  "agent_id": "A001",
  "short_term_count": 10,
  "short_term": [...],
  "successful_patterns": [...]
}
